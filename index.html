GitHub連携設定

GitHubアカウントのリポジトリを自動取得できます。トークンはこのブラウザの localStorage にのみ保存され、 GitHub API への直接通信にのみ使用されます（サーバーには送信されません）。 Private リポジトリも同期したい場合は repo 権限（できれば読み取り専用の fine-grained PAT）のトークンを入力してください。
